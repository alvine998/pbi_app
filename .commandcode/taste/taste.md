# Taste

## Communication
- Prefers terse, short imperative instructions ("check setup...", "now check", "continue") over verbose prompts or back-and-forth clarification. Confidence: 0.8

## Workflow
- Wants debug logging/instrumentation added to new integrations and flows so runtime behavior can be traced (e.g., tagged console logs when wiring up Google Sign-In). Confidence: 0.7
- Expects the agent to execute multi-step tasks autonomously once given a directive ("yes wire up and debug...", "continue") rather than pausing for confirmation at each step. Confidence: 0.7
